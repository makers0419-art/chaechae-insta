# 채채 캐릭터 제작·검수 기준서 v0.3

작성일: 2026-10-28 · 용도: 제작자·이미지 생성 에이전트 인수인계 · 상태: 검증 중인 초안

## 1. 먼저 읽을 사항

이 문서는 승인 마스터의 시각적 특징, 사용자 수정 이력, 현재 에셋을 함께 전달한다. 같은 캐릭터와 화풍으로 제작하고 같은 기준으로 검수하는 것이 목표다. 텍스트만으로 동일한 픽셀의 재생성을 보장하지 않는다. 승인된 에셋은 새로 그리지 않고 원본을 재사용한다.

사용자가 2026-10-28 직접 첨부한 10개 파일이 이 패키지의 권위 있는 선택본 목록이다. Drive 폴더 접속 여부와 무관하게 첨부 파일의 실제 바이트를 사용했다. 이전 v0.1의 추정 목록과 비교 예시는 폐기·대체한다. 10개는 마스터 1개를 포함한 총수다.

최신 확정: 사용자가 이번에 첨부한 세 보정본을 각 자세의 마스터로 명시했다. A07·A08·A09를 이 원본으로 교체하고 보정 필요 상태를 해제한다. 총수는 10개로 유지한다. M00은 기본 외형·화풍 참조, A07·A08·A09는 승인된 시점·자세 마스터다. 사용자가 지정한 원본을 임의로 다시 보정하거나 과거 후보로 대체하지 않는다.

## 2. 참조의 역할과 우선순위

| 참조 | 맡는 역할 | 가져오면 안 되는 것 |
|---|---|---|
| 사용자가 작업에서 지정한 편집 원본 | 보존할 구도·외형·현재 상태 | 다른 대화 이미지로 임의 대체 |
| 승인 마스터 | 캐릭터 정체성·색·배색·브러시·단순화 수준 | 작업에서 요구하지 않은 자세 복사 |
| 승인된 같은 시점의 에셋 | 해당 시점의 체형과 얼굴 원근 보조 | 보정 필요 이미지의 잔질감 |
| 실사 | 자연스러운 행동·관절·시선·눈꺼풀·입매 | 실제 털 한 올·조명·입체 음영·코의 광택 |
| 표시 이미지 | 수정 부위의 위치 | 빨간 선·검은 여백·캡처 테두리 |

작업별 사용자 지시가 이 문서보다 우선한다. 마스터와 편집 원본이 충돌하면, 사용자가 명시한 보존 범위를 지키면서 수정한다. 원본 변경 금지 부위를 화풍 통일 명목으로 다시 설계하지 않는다.

## 3. 외형 고정 규칙

채채의 핵심은 풍성한 밝은 털 속에 작은 얼굴과 짧은 발이 묻힌 형태다. 큰 눈과 긴 주둥이로 귀여움을 만들지 않는다.

| 부위 | 고정 기준 |
|---|---|
| 체형 | 작은 포메라니안의 짧고 컴팩트한 몸통. 등 길이와 털 부피가 누적 수정으로 늘어나지 않음 |
| 얼굴 | 넓은 털 면적 속 작은 이목구비. 표정 변경 시 얼굴 자체를 확대하지 않음 |
| 눈·코 | 정면은 두 눈과 코가 가로로 넓고 높이가 낮은 역삼각형. 코가 아래로 멀어지지 않음 |
| 눈 | 소박한 검은 콩 형태. 작은 안광 하나만 허용. 흰자·큰 반사광·강한 눈꼬리 금지 |
| 코 | 작은 단순한 검정 덩어리. 콧구멍·젖은 표면·정밀한 하이라이트 생략 |
| 주둥이 | 매우 짧고 둔함. 측면에서도 여우·늑대처럼 길게 돌출하지 않음 |
| 귀 | 작고 끝이 둥근 삼각형, 밑부분은 머리털에 묻힘. 끝과 바깥쪽에 검정 포인트 |
| 발 | 짧고 둥근 크림색 덩어리. 다리 윗부분은 몸 털에 묻히고 발끝은 옅고 끊긴 터치 |
| 꼬리 | 현재 측면 에셋에서는 작은 덩어리가 등에 붙은 형태. 다른 자세에 일괄 적용할 전신 규칙은 아님 |

정면의 눈 간격과 삼각형을 측면에 그대로 복사하지 않는다. 원근에 따라 투영은 달라지되, 작은 이목구비와 짧은 주둥이라는 구조를 유지한다. 귀는 같은 두개골에 붙어야 한다. 먼 귀가 가려지는 자연스러운 측면을 허용하되, 작업에서 양쪽 귀를 요구했다면 먼저 그에 맞는 반정면 각도를 선택한다.

## 4. 부위별 털색

| 부위 | 기준 |
|---|---|
| 바탕 | 따뜻한 크림·아이보리. 차가운 회백색·진한 황토색으로 이동 금지 |
| 미간 | 작은 회갈색 세이블 무늬. 표정에 따라 움직이는 눈썹이 아님 |
| 눈 바깥·볼 | 정해진 위치의 회갈색 방향성 터치. 얼굴 전체의 짙은 마스크로 연결 금지 |
| 귀 | 검은 끝·바깥쪽, 밝은 안쪽과 소수의 회갈색 터치 |
| 가슴·배·발 | 밝은 크림색 면 우선. 주변과 비슷한 옅은 베이지로 형태만 암시 |
| 등·몸통 | 선택된 마스터 또는 편집 원본의 배색 보존. 사진의 그림자를 새 회색 무늬로 옮기지 않음 |

색상 코드는 아직 계측·승인되지 않았다. 임의 HEX나 비율을 확정 기준으로 만들지 않는다. '색 변경 금지' 작업은 전체 평균색뿐 아니라 부위별 명도·채도·색상과 세이블 위치를 비교한다. 필압을 강하게 한다는 지시를 털색을 짙게 하는 지시로 해석하지 않는다.

## 5. 브러시·털 질감 고정 규칙

| 항목 | 목표 | 실패 신호 |
|---|---|---|
| 굵기 | 머리 크기 대비 넓고 둔한 크레용 획 | 가는 털선과 세필 |
| 필압 | 한 획의 흐름이 읽히면서 종이 결이 드문드문 비침 | 안개 같은 음영 또는 빈틈없이 눌러 칠한 진한 면 |
| 입자 | 획 내부의 불규칙한 작은 빈틈 | 비늘·조약돌·꽃잎 같은 반복 색점 |
| 겹침 | 획이 개별적으로 읽히는 제한적 중첩 | 작은 터치를 쌓아 표면 전체를 채움 |
| 밀도 | 큰 밝은 면 사이 성긴 방향성 획 | 얼굴·가슴·몸통을 모두 같은 밀도로 채움 |
| 털 단위 | 여러 가닥을 묶은 큰 흐름·덩어리 | 털 한 올씩 분리 |
| 끝처리 | 둔하고 부드럽고 약간 불규칙 | 모든 끝을 날카롭게 잘게 분기 |
| 외곽 | 크림·회갈색 터치가 윤곽을 만듦 | 몸 전체의 닫힌 검정 테두리 |
| 입체감 | 배색과 소수의 터치로 형태 암시 | 정교한 반사광과 연속 음영으로 부피 조각 |

단순화는 세부 획을 생략하는 것이다. 그림 전체를 흐리거나 작은 입자로 뭉개는 것이 아니다. 브러시를 크게 하면서 획 수와 겹침을 그대로 두면 밀도가 높아지므로 함께 줄인다. 모량은 실루엣의 부피이고 묘사 밀도는 내부 획의 개수다. 둘을 분리하여 수정한다.

털 방향은 이마에서 위·바깥으로, 볼에서 옆·아래로, 가슴에서 아래로 흐른다. 방향을 설명하기 위한 최소한의 큰 획만 남긴다. 검정은 눈·코·입·귀 일부에 집중한다. 발은 후속 사용자 지시에 따라 옅고 흐지부지한 경계를 우선한다. 기존 마스터의 검은 발 테두리는 복제할 규칙에서 제외한다.

### 상대 크기 비교법

전체 캔버스에 맞춰 비교하지 말고, 머리의 폭을 같은 크기로 맞춘 뒤 눈으로 본다. 정면과 측면이 다르면 가장 가까운 승인 시점을 함께 사용한다. 서 있는 그림과 누운 그림을 캔버스 폭에 맞추면 선 굵기를 잘못 판단할 수 있다.

검수 시 브러시 크기, 필압, 입자, 겹침, 여백, 끝처리의 여섯 축을 각각 기록한다. 아직 계측된 허용 오차는 없다. 생성 도구가 실제 브러시 파라미터나 색 잠금을 제공한다고 가정하지 않는다.

## 6. 표정·자세 규칙

| 유형 | 핵심 |
|---|---|
| 무표정 | 작은 눈과 작게 다문 입, 표정 근육 과장 없음 |
| 뚱함 | 내려온 윗눈꺼풀, 내려간 입꼬리, 아주 작은 아랫니, 매우 옅은 미간 찌푸림 |
| 시무룩 | 기운이 빠진 눈꺼풀·입매. 뚱함의 불만과 구별 |
| 멍함 | 시선과 입에 힘이 빠짐. 놀람처럼 눈을 확대하지 않음 |
| 졸림 | 편안한 짧은 눈꺼풀 곡선. 눈꼬리 연장과 웃는 초승달 금지 |
| 냠냠 | 시선은 개껌, 한쪽 어금니 쪽으로 물며 작은 비대칭 턱 움직임. 웃음·헐떡임으로 표현 금지 |
| 쿨쿨 | 바닥에 눌린 볼과 힘 빠진 입매. 옆으로 누운 머리 전체에 귀·눈·코 각도를 함께 적용 |

실사에서 반영할 특징은 '10% 실사'처럼 추상적인 수치 대신 '낮아진 윗눈꺼풀', '한쪽으로 압축된 입매'처럼 부위를 명시한다. 자연스러운 표정을 위해 사람 같은 눈썹·큰 흰자·과장된 주름을 추가하지 않는다.

## 7. 공통 프롬프트

아래 고정문 뒤에 작업별 블록을 붙인다. 모델 이름과 API 파라미터는 실제 사용 도구에서 확인하고 별도 실행 기록에 남긴다.

```text
첨부한 승인 마스터를 채채의 외형·털색·배색·브러시·묘사 밀도의 기준으로 사용한다.
실사는 자세·관절·시선·표정만 참고한다. 실사의 세밀한 털, 조명, 코의 광택은 옮기지 않는다.

채채는 따뜻한 크림·아이보리 바탕의 작은 포메라니안이다.
넓은 털 면적 속 작은 눈·코·입, 매우 짧고 둔한 주둥이, 작고 둥근 삼각 귀를 유지한다.
눈은 소박한 검정이며 안광은 아주 작은 점 하나다. 정교한 코·수염점·주둥이 음영을 생략한다.

자세가 바뀌어도 작은 얼굴·짧은 주둥이·배색과 동일한 크레용 표현 수준을 유지한다.
```

## 8. 제작·수정 절차

1. 실제 사용할 승인 마스터와 편집 원본을 확인한다. 파일명보다 해시를 함께 확인한다.
2. 입력마다 역할을 명시한다. 가능하면 마스터와 필요한 실사만 사용하고, 과거 후보를 여러 장 섞지 않는다.
3. 사용자 요청을 변경 영역과 보존 영역으로 나눈다. '70%로'와 '70% 줄이기'를 구분하여 기록한다.
4. 처음부터 최종 자세를 만들고, 표정·화풍 수정은 범위를 제한한다. 직전 수정본만 단독 참조하지 않고 마스터를 계속 함께 사용한다.
5. 원본과 후보를 같은 머리 크기로 비교한다. 필요하면 가슴·볼·발의 동일 크기 확대 부분도 비교한다.
6. 아래 검수표로 결과를 기록하고, 실패 부위만 한 번에 적게 수정한다.
7. 운영 초기 권장 재시도 한도는 동일 결함 3회다. 이는 사용자 확정 규칙이 아닌 제안이다. 한도 뒤에는 자동 통과시키지 말고 검토 대기로 둔다.
8. 승인 후 원본 파일과 생성 기록을 보관한다. 원본을 덮어쓰지 않고 새 버전을 만든다. 중복 요청은 승인 파일을 재사용한다.

이미지 생성의 '보존하라'는 지시는 픽셀 보존 장치가 아니다. 색·몸통 등의 완전 보존이 필수인 작업은 향후 마스크와 원본 재합성 경로를 검증해 사용한다. 이 패키지에는 합성 프로그램이나 이미지 API 자동화가 구현되어 있지 않다.

## 9. 검수표와 승인 조건

| 검사 | 확인할 질문 |
|---|---|
| 입력 | 사용자가 선택한 정확한 원본인가? 최신 마스터인가? |
| 얼굴 | 머리 크기를 맞춰 보았을 때 눈·코·주둥이가 커지거나 길어졌는가? |
| 귀 | 같은 머리에 붙어 있는가? 원근과 회전에 맞는가? |
| 체형 | 등이 길어지거나 몸이 얼굴 대비 과하게 커졌는가? |
| 색 | 부위별 색과 세이블 위치가 보존됐는가? 넓은 회색 음영이 추가됐는가? |
| 브러시 | 획의 굵기·필압·입자가 마스터와 유사한가? |
| 밀도 | 작은 중첩 터치·잔털·반복 색점이 늘었는가? 밝은 면이 남았는가? |

| 출력 | 전신 잘림·배경 후광·원치 않는 문자·표시선이 없는가? |

검수 결과는 통과 / 보정 필요 / 확인 불가로 적는다. 요청 변경과 보존 검사를 모두 통과한 뒤 사용자 승인 상태를 별도 기록한다. 자동 유사도 점수로 사용자의 승인을 대신하지 않는다. 이미 다음 작업으로 넘어갔다고 모든 검사를 통과 처리하지 않는다.

### 이번 선택본에서 확인한 특징

M00·A01·A02·A03은 굵고 길게 구분되는 크레용 획, 밝은 가슴 면, 작은 얼굴 구조를 공통으로 보여준다. A02와 A03은 유사한 감정이지만 별개 선택본이므로 합치지 않는다. 입을 다문 정색을 무표정 대체본으로 이름 바꾸지 않는다.

A04의 멍함은 정면 전신 서기 대신 엎드린 자세다. A05는 사용자가 고른 씹는 원본이다. 예전 대화의 마지막 생성본이 더 최신이더라도 선택본을 우선한다. A06은 두 귀 노출과 낮게 눌린 얼굴, 작은 혀가 핵심이다.

A07·A08·A09는 사용자가 최신 보정본을 마스터로 지정했다. 이 세 파일의 색·자세·부드러운 발을 해당 시점의 기준으로 사용한다. 정면 마스터와의 묘사 차이가 보여도 사용자의 승인 상태를 임의로 취소하지 않는다. 새 수정은 별도 후보 버전으로 만든다.

### 시각 비교

gallery.html에서 이번 확정본 10개를 확인한다. 전체 이미지는 최신 선택본이며 오래된 확대 예시는 삭제했다. 정면 M00의 검은 발 테두리를 다른 자세에 복사하지 않고, 후속 승인본의 옅고 끊긴 발을 우선한다.

## 11. 에이전트 실행 기록 형식

job_record_template.json을 복사하여 작업별로 작성한다. 실사용에서 확인한 모델·도구·파라미터만 적고 추정하지 않는다. 원본과 결과의 해시, 실제 프롬프트, 변경·보존 범위, 검수 결과, 사용자 승인 상태를 보관한다. 비밀키는 저장하지 않는다.

## 12. v1.0 완료 조건

- 이번 사용자 선택본 10개를 이후 에셋 목록의 기준으로 유지. 교체는 사용자의 특정 파일 지시가 있을 때만 시행.
- A07·A08·A09는 이번 사용자 지정으로 자세 마스터 등록 완료. 추가 변경은 별도 버전으로 관리.
- 출력용 글자 포함 여부, 크기, 투명 배경 규격을 별도 확정. 현재 원본의 글자나 배경은 임의 삭제하지 않음.
- 새 자세를 제작해 같은 기준이 통하는지 검증.
- 얼굴 비율·색·획 굵기를 수치화할 경우 실제 선택본에서 계측하고 사용자 확인. 이 문서의 설명은 정밀 계측값이 아님.
- 파일 목록 선택과 화풍 최종 승인을 별도 상태로 관리.
